# 音频原曲目录

这里用于存放已经获得授权、购买并允许在本产品中使用的音频文件。

## 放置规则

- 文件格式：`.mp3`
- 文件位置：`web/public/audio/tracks/`
- 文件名：必须使用项目内配置的 `id`
- 示例：`classic-instrumental-01.mp3` 会播放「01 - 沉默是金」

页面播放逻辑已经做好：如果这里存在同名 `.mp3`，优先播放本地原曲；如果没有找到，就自动回退到当前的本地生成风格版。

## 重要说明

请只放入你拥有版权、已经购买商用授权，或明确被授权用于该产品的音频。内网、本机、测试环境播放也不等于可以使用未授权原曲。

完整曲目和文件名映射见：

- `docs/音频资源接入清单.md`
