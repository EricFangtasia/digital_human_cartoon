# 音频资源接入清单

本项目的音频疗愈模块已经支持优先播放本地原曲文件。把已授权的 `.mp3` 放到：

```text
web/public/audio/tracks/
```

文件名必须和下表 `文件名` 完全一致。没有对应文件时，页面会自动播放本地生成的风格版占位音。

## 合法资源获取建议

- 腾讯音乐旗下商用音乐授权平台「曲易买」：适合采购中文流行、热门版权曲、商用授权曲库。
- 中国音乐著作权协会「音乐作品网上许可系统」：适合按作品申请音乐使用许可。
- COOLVOX 库音：适合采购商用配乐、音效、素材类授权。
- 网易云音乐、QQ 音乐、酷狗等平台：普通会员/下载通常只面向个人收听，不等于可嵌入产品；需要确认商用/产品内播放授权。
- 如果已经有唱片公司、版权方、音乐人、代理机构授权文件，把授权文件和音频文件一起归档保存，方便后续审计。

## 使用流程

1. 从版权方或商用授权平台获取 `.mp3` 音频和授权证明。
2. 按上表重命名文件。
3. 放入 `web/public/audio/tracks/`。
4. 刷新页面，进入「音频疗愈」模块点击曲目。
5. 如果仍提示播放风格生成版，说明文件名、路径或格式不匹配。

## 不建议的做法

- 不要把从普通音乐 App 缓存目录提取的文件放进项目。
- 不要使用短视频平台、网盘、搜索结果里的未知来源音频。
- 不要把未授权原曲提交到公开 GitHub 仓库。
